The fonts are served locally by Django staticfiles and apply only inside
payment receipts (.receipt-container) and certificates (.cert-sheet).
The surrounding CRM keeps its original Sora, DM Sans and DM Mono fonts.
Font Awesome retains its own font for icons. Browsers use Arial or sans-serif
for characters absent from the original fonts.
